# Contributing

Thank you for your interest. At this stage the project takes **issues and discussions only**, not pull requests.

The reason is practical. This repository is generated from a private source tree at every release, so a change merged here would be overwritten at the next release unless it were first brought back into that source by hand. Until there is a policy for outside changes, pull requests will be closed with a pointer to this page.

## What helps most

- **Something did not work.** Open an issue with the release number (the file `VERSION`), what you did, what you expected and what happened. Paste the engine's message exactly; it says why in plain words.
- **Something was unclear.** Say which document or message and what you could not tell from it.
- **A control, question or wording is wrong for your kind of company.** Say what you would change and why. Keep company names, people and records out of it.
- **An idea.** Describe the situation first and the idea second.

## Please do not

- post real company records, evidence, names or contact details in an issue;
- report a security problem in public; read [SECURITY.md](SECURITY.md) instead;
- ask for legal advice. See [DISCLAIMER.md](DISCLAIMER.md).
