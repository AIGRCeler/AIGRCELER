# What each decision needs the decision-maker to say

The tool records the decision-maker's own words. These are prompts for what a useful statement contains, not wording to paste for them.

| Decision | Say |
|---|---|
| Start a stage | Which system, which stage, that you are starting it, and anything you want watched |
| Approve controls | That you have read the list and approve it (name any you want declined) |
| Confirm a lane | Which lane, and why if it is below the suggested one |
| Accept a risk | Which risk, that you accept it, until when or until what event, and on what authority |
| Overrule a finding | Which finding, what you decide instead, and why |
| Waive a control | Which control, why, until when |
| Approve a catalog change | Which change, why, whether to release a new version now |
| Grant an exception | What departs from the rules, why, who, until when |
| Close an incident | That you are satisfied, what changes |
| Containment | What stopgap, why, until when |
